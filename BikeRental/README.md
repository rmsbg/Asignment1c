**Phase 0:** Diese Arbeitskopie verwendet noch die SkiRental-Fachfunktionen.
Die Oberfläche kennzeichnet den Ausgangsstand. Fahrradverwaltung, Stundenmiete,
Fahrradbilder, typabhängige Preise und Extras folgen in den nächsten Phasen.

Start aus diesem Verzeichnis: `go run ./cmd/server`, optional mit `-demo`.
